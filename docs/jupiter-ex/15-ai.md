# ИИ: планировщик, цели, NavMesh

В розничных DLL **нет строки `GOAP`**. В SDK это явно планировщик целей/действий (GOAP-стиль): goal → A* по действиям → план. Документируем оба факта, не путаем.

## Где живёт

Почти всё в **GameServer.dll** / `Game/ObjectDLL`. Движок (`FEAR.exe`) ИИ не планирует — только объекты, пересечения, навигационные запросы через обычный `ILT*`. (**строки**: сервер ~600 AI*, exe ~0 релевантных)

Актор: `CAI : CCharacter` (`AI.h`). Менеджер: `CAIMgr` владеет planner + action mgr. (**SDK**)

## Планировщик (**SDK**)

`CAIPlanner::BuildPlan` — A* (`AIAStarPlanner`) по `CAIActionAbstract`. Результат: `CAIPlan` из шагов `CAIPlanStep` (действие + ожидаемый `CAIWorldState`).

Дальше: `CAIPlan::ActivatePlan` → `ActivateAction` → эффекты `ApplyWSEffect` / предусловия `SetPlanWSPreconditions`.

Цели: `CAIGoalAbstract::BuildPlan`, `CalculateGoalRelevance` (~40 `AIGoal*.h`).

Память: `CAIWorkingMemory` (факты, `FindFactNodeMax`). Сенсоры: ~50 `AISensor*.h`. Данные: `AIDB` (action/goal records).

Это тот же стек, что Pointman `crates/ai` имитирует на своём словаре. Не тащить «современный utility AI».

## Навигация (розница)

Серверные строки (проверены по GameServer.dll): `CAINavMeshGen`, `AINavMesh`, `AINodeCover`, `AINodeCombatOpportunity`, `AINodePickupWeapon`, варнинги packer. `AINavigationMgr` / `AIPathMgrNavMesh` / `AINodeMgr` — имена **SDK**, строк в розничных PE **нет**.

Packed NavMesh лежит в World00p **blinddata**, typeId `0x83f47c31`. Intro: один блоб, `nNum=26`, проп `AINavMesh02.BlindDataIndex`; остальные 6 объектов AINavMesh = −1 (packer склеивает). Layout секции — [22-world00p.md](22-world00p.md).

Первый `u32` блоба — флаг **processed** (`!= 0` = packed). Intro = **1**. Дальше cooked payload: version **6**, `fixed_up`, edges… `SetupNavMesh` (**SDK** `AIMgr.cpp`; розница `GameServer.dll` `0x10059dc0` — начало функции; сама инструкция skip +4 @ `0x10059e32` в [22-world00p.md](22-world00p.md)) делает `pData+4` и кормит `RuntimeSetup`. `InitNavMesh` в SDK — заглушка. Это **не** drift packer/SDK и не version-1 header. Exe blob не парсит, только `GetBlindObjectData` (vtable +0x144). TypeId в GameServer @ `0x1005fe5a` (**ndisasm**, image `0x10000000`).

Стимулы: `AIStimulusMgr`, клиентский дебаг `RenderStimulus`.

Сообщения объектам: `AddGoal <AI> <goal>`, `RemoveGoal`, `GoalSet`.

## Что не ИИ движка

`Light_*` LOD, vis-секторы (`eFS_Vis_*` в frame stats), portal vis — это рендер/мир, не GOAP.
