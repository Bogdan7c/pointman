# Jupiter EX renderer — coverage matrix

Нормативный реестр. Не карта «куда копать потом»: каждая строка — статус доказательства для implementation-ready спеки. Теги: **SDK** / **archive** / **Ghidra** / **capture** / **empirical** / **hypothesis**.

Статусы:

| Status | Значит |
|---|---|
| `unknown` | нет алгоритма, нельзя реализовать без новой улики |
| `partial` | куски есть, для картинки не хватает формулы/стейта/порядка |
| `verified-static` | Ghidra control flow и/или archive `.fx`/формат; capture не подтвердил |
| `verified-capture` | тот же смысл виден в D3D9 до Present |
| `compat-contract` | внутренность закрыта, но есть наблюдаемый контракт + golden (только если внутренность **доказанно** недоступна) |

Image base exe: `0x00400000` (**Ghidra** / PE). Адреса ниже — unpacked `FEAR.unpacked.exe`, не packed `.bind`.

Бинарники и архивы: [20-evidence.md](20-evidence.md). Кадр: [01-frame.md](01-frame.md). Этот файл — индекс дыр; спеки по темам живут рядом.
